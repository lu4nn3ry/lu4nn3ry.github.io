# Checklist de Implementação para um Site de Portfólio de TI

## Estrutura Básica
- [x] Página inicial com apresentação pessoal
- [x] Página "Sobre" com formação e interesses
- [x] Página de projetos com exemplos e links para o GitHub
- [x] Página de contato com e-mail e redes sociais
- [x] Lista de tarefas (To-do) interativa

## Design & UX
- [x] Layout responsivo (funciona bem em mobile e desktop)
- [x] Navegação clara e intuitiva (menu visível e acessível)
- [x] Paleta de cores consistente e agradável
- [x] Tipografia legível e adequada
- [x] Ícones e imagens otimizados

## Conteúdo
- [x] Foto ou avatar profissional
- [x] Descrição detalhada de projetos (tecnologias, desafios, resultados)
- [x] Currículo para download (PDF)
- [x] Seção de depoimentos ou recomendações (opcional)
- [x] Blog ou área de artigos (opcional)

## Funcionalidades Técnicas
- [x] SPA (Single Page Application) com Vue.js
- [x] SEO básico (títulos, descrições, meta tags)
- [x] Analytics (Google Analytics ou similar)
- [x] Formulário de contato funcional (envio de e-mail)
- [x] Dark mode (modo escuro)
- [x] Deploy automatizado (GitHub Pages, Vercel, Netlify, etc.)

## Acessibilidade
- [x] Contraste adequado para leitura
- [x] Navegação por teclado
- [x] Textos alternativos em imagens
- [x] Uso correto de tags semânticas HTML

## Manutenção & Código
- [x] Código comentado e organizado
- [x] README.md explicando o projeto
- [x] Licença de uso (MIT, GPL, etc.)
- [x] Testes básicos (unitários ou de integração, se aplicável)

---

> Marque os itens conforme for implementando para garantir um portfólio completo e profissional!
